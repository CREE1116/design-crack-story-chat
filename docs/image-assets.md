# 이미지 호스팅 및 웹 쇼케이스

스토리챗은 외부 호스팅 이미지를 조합 주소(`{IMG}/카테고리/번호.png`)로 부를 수 있습니다. 이 문서는 **Cloudflare Pages를 통해 이미지를 호스팅하고 웹 쇼케이스 갤러리를 구축하는 방법**입니다. 프롬프트에서 어떻게 부르는지는 [image-output-rules.md](../skills/design-crack-story-chat/references/image-output-rules.md)에 있습니다.

> **이 저장소는 이미지를 직접 생성하지 않습니다.** 어떤 도구로 그릴지는 제작자가 정합니다. 여기서 책임지는 것은 **폴더 구조의 무결성, 깨진 링크 방지, Cloudflare Pages 호스팅 및 웹 갤러리 배포**입니다.
>
> 이미지는 항상 선택 사항입니다. **한 장도 없어도 텍스트만으로 플레이가 성립해야 합니다.** 이 조건을 못 지키면 자산 제작이 출시를 막습니다.

---

## 조합 주소 방식

에셋 목록을 프롬프트에 길게 나열하지 않고, 카테고리와 번호의 조합으로 주소를 만듭니다.

```markdown
{IMG}/장소/21.png
{IMG}/주세은/7.png
{IMG}/몬스터/32.png
```

- `{IMG}`는 치환 자리표시자로 남깁니다. 실제 주소를 통합 프롬프트에 하드코딩하지 않습니다.
- **각 축의 값은 닫힌 목록으로 프롬프트에 명시합니다.** 모델이 번호를 창작하면 전부 깨진 링크가 됩니다.
- **부분 커버리지를 전제합니다.** "해당 번호 파일이 없으면 그 자리만 생략" 규칙을 반드시 넣습니다. 그래야 일부만 만들고도 안전하게 출시됩니다.

---

## 권장 호스팅: Cloudflare Pages + 웹 쇼케이스 갤러리

현재 실전 크랙 생태계에서는 **Cloudflare Pages**를 통한 웹페이지 및 이미지 일체형 호스팅을 표준으로 사용합니다.

```markdown
# Cloudflare Pages 무료 도메인
{IMG} = https://<project-name>.pages.dev

# 또는 커스텀 도메인
{IMG} = https://domain.com/작품ID
```

### Cloudflare Pages를 사용하는 이유:
1. **한국(서울) 엣지 초고속 서빙**: 통신사별 CDN 차단이나 속도 저하 없이 0초대 로딩 제공.
2. **무제한 대역폭**: 무료 티어로도 트래픽 제한 걱정 없이 서빙.
3. **웹 쇼케이스 일체화**: 루트에 `index.html`을 두어 작품 소개, 등장인물 도감(Roster), 일러스트 갤러리를 겸하는 반응형 웹페이지를 동시 배포.
4. **Git 연동 자동 무중단 배포**: GitHub에 이미지 push 시 10초 만에 글로벌 엣지에 자동 배포 및 즉시 캐시 갱신.

## 디렉터리 레이아웃 및 자동 스캐폴딩

```bash
python3 tools/images/deploy.py --scaffold --root ~/내이미지폴더
```

실행 시 아래 구조가 자동으로 생성됩니다:

```text
~/내이미지폴더/
  index.html          # Cloudflare Pages 배포용 웹 갤러리 쇼케이스
  _배치표.md          # 108개 자리 전체 목록 + 채움 상태 현황판
  장소/
  주세은/
  세라/
  몬스터/
  이벤트/
```

- 사람이 폴더 이름을 직접 타이핑하면 오타가 나고, 오타는 조용한 깨진 링크가 됩니다. 자동 생성은 이 실패 경로를 통째로 방지합니다.

## 올리기 전에 축 계약을 검사합니다

그림을 폴더에 넣은 뒤 `deploy.py`로 파일 이름의 일치 여부를 검사합니다:

```bash
python3 tools/images/deploy.py --check --root ~/내이미지폴더
```

| 상황 | 판정 |
|---|---|
| 목록에 없는 파일 | **중단** — 오타이거나 축 목록이 낡음 |
| 목록에 있는데 파일이 없음 | **통과** — 부분 커버리지는 정상 |
| 과도하게 큰 파일 | 경고 또는 중단 |

없는 파일을 실패로 치면 안 됩니다. 프롬프트가 이미 "조합이 없으면 그 자리만 생략"을 규정하므로 **부분 배포가 정상 상태**입니다. 반대로 목록에 없는 파일은 반드시 막습니다 — 프롬프트와 자산이 갈라졌다는 신호니까요.
