# 캐릭터 누끼·배경 합성·보케

캐릭터는 잘 나왔지만 배경 품질이 들쭉날쭉하거나, 같은 장소의 여러 컷을 통일하려는 요청에 적용한다. 기본 방향은 **인물 보존·누끼 → 조금 굵은 외곽 보더 → 검수된 배경 합성 → 배경에만 약한 보케**다. 이미지 제작 요청이 없는 서사 작업에서는 실행하지 않는다.

## 기본 실행: 이미지 두 개를 받는 Python 도구

사용자가 누끼·보더·배경 합성을 요청하면 `tools/images/composite_portrait.py`를 기본으로 실행한다. 생성형 이미지 편집으로 대체하지 않는다. 인물 원본 RGB를 다시 그리지 않고 로컬 분할 모델로 알파 마스크를 얻어 Pillow로 합성한다.

```bash
uv run tools/images/composite_portrait.py character.webp background.webp
```

기본 출력은 인물 원본 옆 `character-composite.png`와 `character-composite-cutout.png`다. 인물 원본 크기·구도를 유지하고 배경을 중앙 크롭해 채운다. 배경 글자·배지도 크롭에 남으면 함께 처리되므로 미리 원본을 확인한다. 첫 실행은 의존성과 누끼 모델을 내려받으며 이후 캐시를 재사용한다. 이미지 자체를 외부 편집 서비스에 보내지 않는다. uv가 없으면 Python 3.11~3.13 환경에 `rembg[cpu]`, `pillow`, `scipy`를 설치해 실행한다.

- **그린/블루 스크린으로 뽑은 컷은 색상 키잉이 기본이다.** 분할 모델은 인물을 한 덩어리로 보아 머리카락 사이 틈을 메워 버린다. 그 틈은 실제로 스크린 색이므로 색으로 키잉하면 열린다. 도구가 스크린을 감지하면 자동으로 그 경로를 타고, 없으면 분할 모델로 넘어간다. `--key model`로 항상 모델을, `--key chroma`로 항상 키잉을 강제한다.
- 스크린 판정 임계값은 이미지에서 산출한다. 같은 배경도 회차에 따라 선명도가 달라 고정값을 쓰면 멀쩡한 컷이 조용히 누락된다. 231컷 배치에서 고정값 때문에 32컷이 모델로 새어 나간 적이 있다.
- 분할 모델을 탈 때 기본은 일러스트용 `isnet-anime`. 사진은 `--model isnet-general-use`를 쓸 수 있다.
- `--border 8 --border-color '#fff8ec' --blur 5`로 보더 픽셀 두께·색·배경 Gaussian 흐림 반경을 조절한다. 기본은 짧은 변의 0.8% 보더, 0.6% 흐림이다. 실제 광학 보케나 깊이 추정을 하는 도구는 아니다.
- `--out result.webp`로 출력 경로를 바꾼다. 기존 출력은 `--overwrite`가 없으면 보호하며 입력 덮어쓰기는 항상 금지한다.
- 스크린을 키잉한 컷은 반투명 픽셀에서 스크린 색을 **역산해 뺀다**. 부드러운 머리카락 경계는 인물과 스크린이 한 픽셀에 섞인 상태(`색 = 인물×알파 + 스크린×(1-알파)`)라, 녹색 채널만 누르면 올리브색 테로 바뀔 뿐이다. 알파로 나눠 인물 색을 복원해야 테가 사라진다.
- 보더는 두 단계로 다듬는다. 먼저 이진 알파를 흐린 뒤 다시 절반에서 자른다. 곡률이 제한되어 윤곽이 둥글어지고, 구멍을 메우는 방식과 달리 반경보다 넓은 틈은 살아남아 흰 덩어리가 생기지 않는다.
- 그 실루엣을 벗어난 잔가닥은 **잘라낸다.** 남겨 두면 선이 가닥마다 따라붙어 찢긴 종이처럼 보이고, 그 구간만 선을 빼면 보더가 있는 곳과 없는 곳이 섞여 어정쩡해진다. 잘라내면 한 줄이 인물 전체를 균일하게 감싸고 머리 형태는 유지된다. 잔가닥까지 살리려면 `--keep-wisps`를 쓴다.
- 알파 계단 정리 반경은 `--smooth`로 조절한다(기본 짧은 변의 0.2%). 잡티에는 테를 두르지 않는다.
- `--shrink`는 누끼 경계를 안으로 깎는 픽셀 수(기본 2)다. 스크린 색이 짙게 물린 경계 픽셀은 색을 눌러도 올리브색 테가 남아, 잘라내는 편이 낫다. `--despill`은 경계에서 스크린 색을 빼는 밴드 폭(기본 짧은 변의 1.2%)이다. 인물 내부의 초록 눈이나 파란 옷은 건드리지 않는다.
- 투명 이미지 입력은 기존 알파를 재사용한다. 단 실제로 투명한 픽셀이 1% 이상일 때만이다. NovelAI 계열이 뽑는 PNG는 알파 채널이 있어도 사실상 전부 불투명하고 안티에일리어싱 픽셀 때문에 최솟값만 255 미만인데, 그것을 누끼로 착각하면 분할을 건너뛰고 결과가 원본과 똑같이 나온다. 분할이 잘못되면 원본 크기의 흑백 마스크를 `--mask corrected-mask.png`로 전달한다. 흰색=인물, 검정=배경이다.
- 자동 누끼는 완벽하지 않다. 결과를 실제로 열어 잘린 신체·잔여 배경·보더를 확인하고 실패한 부분을 보고한다. 도구는 광원·접촉 그림자·포즈를 다시 그리지 않는다. 그런 보정은 별도 요청 범위에서 수행한다.

## 작업 흐름

1. **배경 기준을 정한다.** 같은 장소·시간대의 컷은 검수된 배경과 공통 색온도·밝기·흐림 정도를 재사용한다. 구도가 달라지면 배경 크롭·인물 위치를 조정하되 카메라 높이와 원근이 맞지 않는 배경을 억지로 쓰지 않는다. 프리셋은 필요할 때 기존 `build/assets/` 자산 기록에 남긴다.
2. **인물을 분리한다.** 얼굴·표정·포즈·체형·의상·소지품을 보존하고 머리카락 끝, 손가락 사이, 반투명 천과 액세서리까지 마스크를 확인한다. 기존 배경색이 테두리에 남는 현상과 흰 띠를 제거한다. 인물에 닿은 의자·난간 등은 함께 보존하거나 새 배경의 지지물과 접촉이 맞도록 처리한다.
3. **누끼 바깥에 보더를 만든다.** 기본은 스티커처럼 인물 전체 실루엣을 감싸는 조금 굵은 외곽선이다. 최종 이미지 짧은 변의 약 0.6~1.0%(1024px 기준 6~10px)를 시작점으로 삼고 출력 크기에 맞춰 조절한다. 흰색·아이보리를 기본으로 배경과 구분되는 색을 선택한다. 알파 실루엣 바깥으로 확장해 얼굴·의상 내부를 침범하지 않게 하고, 여러 소지품이 겹친 내부 경계마다 선을 두르지 않는다. 떨어진 배경 조각·작은 알파 잡티는 먼저 제거해 테두리가 잡티까지 감싸지 않게 한다. 머리카락 미세 가닥마다 울퉁불퉁하게 추적하기보다 외곽을 부드럽게 정돈하되 헤어 실루엣은 보존한다. 보더는 경계 정리용이며 잘린 손가락·머리카락을 숨기는 수단이 아니다. 사용자가 자연스러운 무테 합성을 원하면 생략한다.
4. **배경을 맞춰 합성한다.** 인물 크기·시점·광원 방향·색온도를 맞춘다. 발·좌석 등 실제 접촉부에는 필요한 접촉 그림자를 더한다. 인물 자체를 크게 다시 그려야 할 만큼 조명이 충돌하면 호환되는 배경을 고른다.
5. **배경에만 약한 보케를 적용한다.** 인물과 실루엣은 선명하게 유지하고 먼 배경부터 자연스럽게 흐린다. 인물과 같은 초점면의 바닥·접촉 물체까지 똑같이 흐리지 않는다. 장소를 식별할 구조는 남기고, 점광원이 있는 장면에서만 자연스러운 빛망울을 살린다. 단순 블러를 위해 임의의 발광 원을 흩뿌리지 않는다. 깨진 구조·잘못된 원근은 보케로 덮지 말고 배경을 교체하거나 먼저 수정한다.
6. **대표 한 컷을 검수한 뒤 확장한다.** 원본과 나란히 비교해 인물 변형 여부를 확인하고, 전체 구도와 확대된 머리카락·손·접촉부를 모두 본다. 누끼 파일이 있으면 밝고 어두운 바탕에서 알파 경계를 확인한다. 보더 굵기·색·곡선이 일정한지, 좁은 틈이 뭉개지거나 잡티 주위에 테두리가 생기지 않는지 확인한다. 배경이 선명한 컷과 흐린 컷이 섞이지 않도록 일괄 결과를 함께 확인한다. 실패한 컷만 수정한다.

## 별도 생성형 편집을 요청한 경우의 지시 예시

> 첫 번째 이미지의 인물을 두 번째 이미지의 배경에 합성한다. 얼굴, 표정, 머리 모양, 포즈, 의상과 소지품을 유지한다. 기존 배경을 제거하고 가는 머리카락과 반투명 가장자리를 자연스럽게 보존한다. 누끼 바깥에 조금 굵은 아이보리 보더를 둘러 스티커처럼 정돈한다. 보더는 최종 이미지 짧은 변의 약 0.8% 두께로 시작하고 인물 내부를 덮지 않는다. 떨어진 작은 잡티는 먼저 제거하고 실루엣 바깥선을 부드럽게 연결한다. 배경 원근과 광원에 맞게 배치하고 필요한 접촉 그림자를 넣는다. 인물은 선명하게, 배경은 장소를 알아볼 수 있을 정도의 약한 보케로 처리한다. 빛망울은 기존 점광원에만 적용한다. 테두리 번짐과 기존 배경색 잔상을 없앤다.

장면에 따라 보존할 접촉 물체, 원하는 시간대와 구도를 구체화한다. 원본 보존을 지시했다는 사실만으로 실제 보존이 검증된 것으로 간주하지 않는다.

## 산출물과 완료 기준

- 원본을 보존하고 합성본을 별도 저장한다. 도구가 지원하면 재사용할 투명 누끼 PNG와 배경도 함께 보관한다. 최종 업로드용 WebP 변환·번호화는 [image-assets.md](image-assets.md)를 따른다.
- 배경 기준과 실제 사용한 원본·배경, 보더 색·최종 해상도 대비 굵기·보케 설정 또는 편집 지시를 기존 자산 기록에 남겨 후속 컷에서 재사용한다. 모델 편집은 동일 지시만으로 동일 결과를 보장하지 않으므로 대표 결과도 참조한다.
- 완료 보고에는 합성 결과를 보여주고 인물 보존·경계·광원·배경 일관성의 검수 여부를 적는다. 편집 지침 추가와 실제 이미지 편집 완료를 구분하며, 합성 요청만으로 호스팅·배포를 실행하지 않는다.
