## 역할과 관계 (무대 훅과 현장 큐시트)

크랙의 도입부는 **플레이어가 읽는 겉면**과 **AI가 읽는 이면**이 1:1로 맞물려 작동합니다.

| 구분 | **프롤로그 (`build/prologue.md`)** | **시작 프롬프트 (`build/start-prompt.md`)** |
|:---:|---|---|
| **소비 주체** | **플레이어**가 방 입장 시 읽는 완성 원고 | **AI 모델**이 첫 턴(T1)에 실행하는 큐시트 |
| **분량 상한** | ≤ 1,000자 | ≤ 1,000자 |
| **핵심 역할** | 세계관 줌인 + 시각적 무대 + 즉각적 위기 + 압박 마감 | 앵무새 방지 + 1턴 선언 수용 + 공방 유지 + T1 상태창 |
| **마지막 줄** | *"자, 어떡할래. [플레이어 호칭]."* (선택지 배제) | *"T1 상태창 출력 및 팽팽한 대치 상태로 마감"* |

## 범용 프롤로그 7단계 줌인(Zoom-in) 공식

플레이어가 방에 들어오자마자 30초 만에 세계관에 몰입하고 타이핑을 치게 만드는 7단계 점진적 카메라 줌인 구조입니다.

```
[1단계] 거시 세계사 (2줄)   : 시대/연도, 대재앙/전쟁, 세상이 바뀐 꼴 (드라이 유머 비유)
         ⬇
[2단계] 미시 무대 (2줄)     : 현재의 도시/거점/학원/가문, 질서를 잡은 세력과 칙칙한 현실
         ⬇
[3단계] 직업/정체성 (1줄)   : 가장 위험하거나 특수한 행동을 하는 자들의 집단
         ⬇
[4단계] 주인공 확정 (1줄)   : "그리고 너. 축하한다, 네가 바로 그 [직업/호칭]이다." (1줄 훅)
         ⬇
[5단계] 일상 ➡️ 돌발 위기   : 가벼운 일상/의뢰로 시작했다가 현장에 터진 돌발 변수
         ⬇
[6단계] 대치 및 조력자 개입 : 적/라이벌 난입(짤+대사) + 아군/동료의 다급한 무전·외침(짤+대사)
         ⬇
[7단계] 딜레마 & 압박 마감  : 방치 시 벌어질 파멸 해설 ➡️ "자, 어떡할래. [호칭]."
```

## 범용 시작 프롬프트 4단 핫스타트 공식

프롤로그의 마지막 질문을 이어받아 AI가 첫 응답을 영화의 오프닝 액션처럼 뽑아내도록 통제하는 큐시트입니다.

### 📐 범용 시작 프롬프트 슬롯 템플릿
```markdown
# [첫 턴(T1) 부트스트랩 및 오프닝 실행 지침]

## 1. 핫 스타트 및 앵무새 방지 (Anti-Echo & Zero Friction)
-프롤로그 세계관 요약, 지난 줄거리, 첫 인사말 반복 출력 절대 금지
-프롤로그 마지막 대치 순간([적/라이벌]과의 조우, [조력자]의 경고 직후)에서 즉각 전개
-ⓤ의 첫 입력(대사·행동·무기·*text* 자유설정)을 왜곡/검증/설문 없이 100% 사실로 수용하여 첫 액션 판정

## 2. 첫 턴 연출 및 갈등 유지 규칙
-현장의 감각적 압박([적의 공격/압도적 기세/사교계의 날 선 시선])을 단문 중심으로 속도감 있게 묘사
-사건 조기 종결 금지: 단번에 해결되지 않으며, 합(合) 단위 공방/치열한 탐색전 유지
-[조력자/동료]의 능동적 개입(지원 사격, 서포트 무전, 엄호, 맞장구)을 대사로 즉시 투입
-ⓤ의 대사·행동·내면 대리서술 절대 금지, 팽팽한 다음 턴 대치 상황으로 마감

## 3. 분량 및 톤 기준선 확립 (오프닝 앵커링)
-세션 전체 서술량의 기준선이 되도록 [장르 특화 분위기: 드라이/긴박/우아/유쾌] 톤으로 적정 밀도 서술

## 4. T1 초기 상태창(HUD) 렌더링 계약
-매 응답 최하단에 아래 형식의 초기 상태창을 반드시 출력할 것:
```Info
[🔈] T1 | ⚪
[📅] [기본 날짜/시간]
[📍] [프롤로그 현장 위치]

[👤] [ⓤ 프로필/장비] | [기본 신분/등급]
[👥] 현장/통신: [조력자 이름]([현재 행동/지원 상태])
━━━━━━━━━━━━━━
[상태] [초기 상태 이모지: ⚔️교전 / ⚠️대치 / 🎭사교탐색 / ☕일상 등]
[상황] [프롤로그 직후 현재 맞닥뜨린 국면 객관적 사실 1줄 요약]
```
```

## 4대 대표 장르별 페어링 설계 예시

### 1. SF / 사이버펑크 / 생존
- **프롤로그 훅**: 2133년 침략 ➡️ 지하 벙커도시 에덴 ➡️ 생존자 '러너' ➡️ 3급 아머트론 난입 ➡️ 통신장교 주세은 무전 ➡️ *"자, 어떡할래. 러너."*
- **시작 프롬프트**: T1 즉시 시작, ⓤ 장비 선언 100% 수용, 아머트론 육중한 공격과 주세은 무전 개입, T1 상태창(`[상태] ⚔️교전 / 아머트론 난입`) 출력.

### 2. 판타지 명가 / 정치 암투 / 영지물
- **프롤로그 훅**: 선황 서거 5년 ➡️ 후계자 싸움의 도가니 공작가 ➡️ 쫓겨난 망나니 서자 ➡️ 연회장 독살 미수 발생 ➡️ 제1공자의 비열한 도발 ➡️ 전속 시종의 귓속말 ➡️ *"자, 어떡할래. 공자님."*
- **시작 프롬프트**: T1 즉시 시작(연회장 침묵), ⓤ의 잔 처리 행동 즉시 수용, 제1공자의 시선 압박과 시종의 엄호, T1 상태창(`[상태] 🎭사교암투 / 독살 대치`) 출력.

### 3. 현대 판타지 / 헌터 / 레이드물
- **프롤로그 훅**: 게이트 사태 10년 ➡️ 협회 관리구역 ➡️ 목숨 건 F급 짐꾼 ➡️ 게이트 붉은색 돌연변이(레드게이트) ➡️ 심연 거미 괴수 난입 ➡️ 파티 탱커의 방벽 스킬 ➡️ *"자, 어떡할래. 헌터."*
- **시작 프롬프트**: T1 핫스타트(괴수 돌진), ⓤ의 각성/무기 선언 즉시 수용, 탱커의 방어선 사수 대사, T1 상태창(`[상태] ⚔️레이드 / 레드게이트 파열`) 출력.

### 4. 아카데미 / 청춘 / 미스터리 / 로맨스
- **프롤로그 훅**: 백 년 전통 명문고 ➡️ 7대 괴담의 소굴 구관 동아리실 ➡️ 폐부 위기 오컬트부 부장 ➡️ 대낮에 열린 금기의 비밀 금고 ➡️ 들이닥친 깐깐한 학생회장 ➡️ 소꿉친구 부원의 약점 서류 건넴 ➡️ *"자, 어떡할래. 부장."*
- **시작 프롬프트**: T1 즉시 시작(서류철 내리치는 소리), ⓤ의 변명/대처 수용, 소꿉친구의 속닥거림 개입, T1 상태창(`[상태] ☕부실대치 / 폐부 위기`) 출력.

## 자주 범하는 안티패턴 및 검증 체크리스트

### ❌ 프롤로그 안티패턴
1. **유저 대리 행동/심리 작성**: *"크리는 두려움에 떨며 뒷걸음질 쳤다"* ➡️ **절대 금지**. 외부 환경과 적의 위협만 서술할 것.
2. **유치한 번호 선택지**: `1. 도망친다 2. 맞서 싸운다` ➡️ **배제**. 질문과 딜레마 던지기로 자연스러운 자유 입력 유도.
3. **지루한 거시 역사 나열**: 3문단 내내 연표만 읊다가 끝남 ➡️ **2줄 이내로 축약**하고 즉시 유저의 현장 위기로 줌인.

### ❌ 시작 프롬프트 안티패턴
1. **프롤로그 앵무새**: AI가 첫 응답에서 프롤로그 배경이나 자기소개를 다시 읊음 ➡️ **Anti-Echo 명시**.
2. **프로필 설문조사 강요**: *"이름과 직업, 사용하는 마법을 말해주세요"* ➡️ **절대 금지**. 1턴 `*text*` 입력을 사실로 즉시 확정.
3. **위기 조기 종결 (김빠짐)**: 유저가 칼을 휘두르자마자 보스가 즉사함 ➡️ **합 단위 공방 유지**.
