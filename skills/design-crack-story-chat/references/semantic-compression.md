## 목표

프롬프트는 문학적 미문이 아니라 모델이 정확히 복원할 수 있는 **최소 엔트로피 문자열**입니다. 문장미, 친절한 설명, 자연스러운 연결어는 사용자에게 보이지 않는 시스템 프롬프트에서 불필요한 토큰 낭비입니다.

압축은 단순 삭제가 아니라 `긴 서술형 문단 ➡️ 표준 Syntax 구조 + 고유 편차`로 치환하는 공학적 작업입니다.

---

## 보이는 글과 숨은 글 분리

- **보이는 글 (Visible Prose)**: 프롤로그, 실제 본문 서술·대사, 시작 상황 지문. 자연스러움, 감각적 묘사, 가독성 최우선.
- **숨은 글 (Hidden Prompt)**: 통합 시스템 프롬프트, 인물 명부, 세계관 정의, 키워드북 본문. 전보체, 파이프(`｜`), 1줄 정의, 기호 적극 활용.

## 위험도 기반 비대칭 선택적 압축 전략 (Risk-Weighted Compression)

모든 규칙을 균일하게 줄이지 않습니다. **사고가 발생했을 때의 치명도(위험도)**에 따라 압축 강도를 의도적으로 다르게 배분합니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 고위험 핵심 규칙 (ⓤ 자율성, 6중 잠금, 결정권)               │
│    ➡️ 억지 압축 지양 + 대표 실패 패턴 예시 1개(Golden Example) 명시│
│    (예: {user}: *공격한다* ➡️ 나레이션이 ⓤ 조종·전투 전과정 서술)   │
├─────────────────────────────────────────────────────────────┤
│ 2. 저위험 스타일/나열형 규칙 (톤앤매너, 성격, 배경)           │
│    ➡️ 구분자(·, +, ,)로 5줄 서술을 1줄로 극압축                 │
│    (예: 톤:반말+차분한말투·은어·언어유희·농담,드라이/데드팬 유머)  │
├─────────────────────────────────────────────────────────────┤
│ 3. 금지/허용 대비 규칙 (Prohibition + Allowance)             │
│    ➡️ 별도 문단 분리 없이 1문장에 통합 대조                    │
│    (예: 비하·설교 금지. 서사내 불이익·패배·거절은 금지대상 아님) │
├─────────────────────────────────────────────────────────────┤
│ 4. 채움형 키워드북 트리거 (Universal Punctuation Fillers)     │
│    ➡️ [.,,,",*,INFO] 등 문장부호로 상시 로드 모듈화            │
└─────────────────────────────────────────────────────────────┘
```

### 1. 단일 골든 예시 원칙 (Single Golden Example Principle)
- 규칙을 설명할 때 예시를 3~4개씩 나열하면 수백 자가 낭비됩니다.
- **가장 대표적인 탈옥/실패 패턴 1개**만 괄호 안에 명시하고, 나머지는 AI의 일반화 추론 능력에 맡깁니다:
  ```text
  -AI 임의로 ⓤ입력을 보강·곡해·예측 후 다음행동예측묘사 금지 (예:{user}: *공격한다*→나레이션:ⓤ를 조종·전투 전과정 서술)
  ```

### 2. 세부 항목 병렬 압축 (`·`, `+`, `,` 활용)
- 5개 문장으로 길어질 톤/성격 설명을 구분자로 1줄 압축:
  ```text
  -톤:반말+차분한말투·은어·언어유희·농담,드라이/데드팬 유머
  ```

### 3. 금지선과 예외의 1줄 통합 대조
- "금지 사항 나열 문단"과 "예외 허용 문단"을 나누지 않고 1줄로 통합:
  ```text
  -금지선: 서술자가 ⓤ를 비하·비꼼·평가·논평·훈계·설교하지않음. 서사내 불이익·패배·거절·갈등은 금지대상 아님
  -결정권: 자발적 사건의 최종 결정은 ⓤ 권리. 단, ⓒ의 선제적 능동성(고백, 기습 등)은 적극 허용
  ```

## 3대 실전 극압축 표준

### 1. 1인 1줄 10대 슬롯 파이프(｜) 인물 압축
```text
▶[이름]:[성별｜소속/직책｜나이｜이명｜MBTI·에니어그램｜성격키워드｜등급/경지｜무기/능력｜외형특징｜말투/특징]
```
- **예시**:
  ```text
  ▶세라:[♀｜벌처 정보상｜29｜새벽까마귀｜ENTP·7w8｜호전적·모성·다정·온화·살벌·상냥｜A급 정보원｜모노나이프｜크롬:광학안구｜흑발 롱헤어, 슬릿 드레스]
  ▶서유진:[♀｜뱅가드 통신장교｜24｜은빛여우｜ISTJ·1w9｜냉철·헌신·츤데레｜B급 지휘관｜통신단말·권총｜크롬:신경링크｜은발 단발, 안경, 제복]
  ```

### 2. 3줄 연표화 기법
```markdown
## 타임라인
- [과거 기점 1]: [대재앙/전쟁/침략 발발 및 구체제 붕괴]
- [과거 기점 2]: [방어선 후퇴, 거점/벙커 설립, 핵심 세력 형성]
- [현재 시점]: [현재 당면한 핵심 생존/갈등 상황]
```

### 3. 1줄 사전식 용어 정의
```markdown
## 핵심 세력 및 용어
- 뱅가드: 흑호부대 생존자 기반 방위 조직
- 벌처: 지상 고물 및 암시장 장악 마피아 세력
- 러너: 지상 폐허로 나가 자원을 회수하는 베테랑
- 크롬: 신체에 부착·대체·개조하여 사용하는 사이버웨어
- 등급: 5급(최하)~1급(베테랑), 격외:ZERO
```

## 압축 문법 및 기호 승격

| 기호 | 원래 문장 | 승격 의미 |
|:---:|---|---|
| `→` | `~하면 ~한다`, `~이므로 ~로 전환` | 조건 ➡️ 행동 / 인과 전환 |
| `｜` | `[항목1], [항목2], [항목3]` | 고정 스키마 내 슬롯 구분자 |
| `·` | `~함과 동시에 ~한` | 병렬 속성 묶음 |
| `×` | `~하지 않는다`, `~를 엄격히 금지한다` | 금지 |
| `≠` | `~는 ~를 뜻하지 않는다` | 오해 방지 경계 |
| `≤ / ≥` | `최대 ~개까지`, `최소 ~이상` | 수치 한계 |

## 데이터와 규칙의 이원화 문법

1. **데이터 영역 (인물, 연표, 사전, 상태창)**:
   - 조사와 공백을 최대한 배제하고, `｜`, `·`, `:` 기호 기반 전보체로 극압축합니다.
2. **규칙 영역 (주도권, 자율성 잠금, 페르소나, 분량 룰)**:
   - 모델의 오해나 탈옥을 방지하기 위해 단일 골든 예시를 동반한 선명한 단문 명령문으로 작성합니다.
