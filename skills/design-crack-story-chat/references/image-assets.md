## 적용 범위와 기본 원칙

스토리챗은 외부 호스팅된 이미지를 마크다운 문법(`![](URL)`)으로 실시간 호출할 수 있습니다.

- **[image-output-rules.md](image-output-rules.md)**: 시스템 프롬프트에서 이미지를 **어떤 번호(a/s)로 매핑하고 언제 출력할 것인가 (런타임 출력 제어)**
- **[image-assets.md](image-assets.md) (본 문서)**: 이미지를 **WebP로 변환하고, 번호화된 디렉터리에 배치하며, Cloudflare Pages와 쇼케이스 웹페이지로 호스팅하는 방법 (호스팅 & 웹 배포)**

> [!IMPORTANT]
> **이 스킬은 AI 이미지를 직접 생성하지 않습니다.** 그림을 그리는 도구(Midjourney, NAI, SD, 외주 등)는 제작자가 자유롭게 선택합니다. 스킬이 책임지는 것은 **WebP 변환, 디렉터리 무결성 검사, Cloudflare Pages 호스팅 및 반응형 웹 갤러리 배포**입니다.
> 
> 이미지는 항상 선택 사항입니다. **단 한 장의 이미지가 없어도 텍스트만으로 완벽히 플레이가 성립**해야 합니다.

## 표준 번호화 및 a/s 접두사 에셋 구조

토큰 효율과 씬 분류를 위해 인물은 **2자리 숫자 ID**로 치환하고, 파일명은 **`a`(일반) / `s`(성인)** 접두사를 부여하여 `.webp` 포맷으로 관리합니다.

```text
my-story-assets/
├── index.html            # 작품 소개 및 인물별 일러스트 갤러리 웹페이지
├── styles.css            # 반응형 다크 테마 스타일시트
├── app.js                # 인물 필터링 및 동적 카드 렌더링 스크립트
├── banner.webp           # 웹페이지 상단 대표 히어로 배너
├── thumbnail.webp        # 웹페이지 대표 썸네일
├── scene/                # 배경 및 장소 이미지
│   ├── a01.webp (광장)
│   ├── a02.webp (암시장)
│   └── a21.webp (지상 폐허)
├── 01/                   # 01번 인물 (예: 에리카)
│   ├── a01.webp (기본·평상)
│   ├── a02.webp (진지·경계)
│   ├── a03.webp (전투)
│   ├── s01.webp (19+ 합방 애무)
│   └── s02.webp (19+ 정상위)
├── 02/                   # 02번 인물 (예: 엘리아)
│   ├── a01.webp (기본·단정)
│   ├── a06.webp (통신·무전)
│   └── s01.webp (19+ 키스/애무)
├── mob/                  # 적/몬스터/메카닉
│   ├── a31.webp
│   └── a32.webp
└── event/                # 단체/특수 컷씬
    ├── a01.webp
    └── s01.webp
```

## WebP 일괄 변환 파이프라인

모든 이미지는 용량 절감(PNG 대비 70~80% 감소)과 모바일 0초대 로딩을 위해 **반드시 WebP 포맷으로 변환**하여 업로드합니다.

```bash
# cwebp CLI를 사용한 일괄 변환 예시
for f in *.png *.jpg; do
  [ -f "$f" ] && cwebp -q 85 "$f" -o "${f%.*}.webp" && rm "$f"
done
```

## Cloudflare Pages 호스팅 아키텍처

현재 실전 크랙 생태계에서는 **Cloudflare Pages**를 통한 웹페이지 + 이미지 동시 호스팅이 표준으로 사용됩니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 한국(서울) 엣지 POP 0초대 로딩 : 국내 통신사 차단/렉 제로    │
│ 2. 무제한 대역폭 (무료 티어)      : 트래픽 비용 걱정 없음    │
│ 3. 무료 서브도메인 & 커스텀 도메인 : *.pages.dev / domain.com │
│ 4. Git Push 자동 무중단 배포      : 커밋 즉시 10초 만에 갱신 │
│ 5. 웹 쇼케이스 갤러리 일체화      : 브라우저 접속 시 도감 출력 │
└─────────────────────────────────────────────────────────────┘
```

### 배포 URL 형태
```markdown
# Cloudflare Pages 무료 도메인
{IMG} = https://<project-name>.pages.dev

# 개인 커스텀 도메인
{IMG} = https://domain.com/작품ID
```

## 쇼케이스 웹페이지(HTML/CSS/JS) 템플릿 아키텍처

루트에 `index.html`, `styles.css`, `app.js` 3개 파일을 배치하여 **작품 소개, 등장인물 도감(Roster), 일러스트 갤러리를 겸하는 반응형 다크 테마 웹페이지**를 동시에 운영합니다.

### 1. `app.js` 인물 데이터 구조
```javascript
const characters = [
  { id: "01", name: "에리카 아르덴", group: "student", type: "기사학부 · 1학년", role: "깐깐한 정석파 라이벌", quote: "기본을 무시한 검술은 검술이 아니야." },
  { id: "02", name: "엘리아", group: "student", type: "마도학부 · 2학년", role: "냉철한 서포터", quote: "30초만 버텨. 지원 보낼 테니까." }
];
```

### 2. 특징
- **탭 필터링**: 전체, 학생(`student`), 교수진(`faculty`), 진영별 실시간 필터링
- **호버 인터랙션**: 마우스 오버 시 인물 명대사(`quote`) 팝업
- **지연 로딩**: `loading="lazy"` 속성을 통해 수십 명의 고해상도 이미지가 있어도 초기 로딩 지연 없음
- **캐시 버스팅**: `revision: "20260826-2"` 태그를 통해 이미지 교체 시 브라우저 캐시 즉시 갱신

## 축 계약 검사 및 배포 도구

`tools/images/deploy.py` 도구를 사용하여 폴더 골격, 배치표, 쇼케이스 웹 템플릿을 한 번에 생성하고 무결성을 검사합니다.

```bash
# 1. 축 목록대로 빈 폴더, _배치표.md, 웹 템플릿(index.html, styles.css, app.js) 자동 생성
python3 tools/images/deploy.py --scaffold --root ~/내이미지폴더

# 2. 그림을 폴더에 넣은 뒤 파일 이름 및 축 계약 검사
python3 tools/images/deploy.py --check --root ~/내이미지폴더
```

### 검사기가 잡는 오류
- **목록에 없는 파일명**: 오타로 인한 깨진 링크 방지
- **WebP 외 확장자**: `.png`, `.jpg` 감지 시 `.webp` 변환 알림
- **과도하게 무거운 파일**: 모바일 로딩 지연 방지

## 금지 패턴 및 체크리스트

1. **무작위 파일명 사용 금지**: `image1.png`, `temp.jpg` 등 축과 무관한 파일명 배제. 반드시 `{id}/a01.webp` 또는 `{id}/s01.webp` 사용.
2. **WebP 미변환 업로드 금지**: 원본 PNG(수 MB)를 그대로 올려 모바일 트래픽을 낭비하지 말 것.
3. **이미지 의존적 텍스트 작성 금지**: 이미지가 로드되지 않아도 텍스트만으로 모든 상황이 완벽히 전달되어야 함.
4. **배포 전 검사 필수**: `deploy.py --check`로 파일명 일치 여부 확인 필수.
