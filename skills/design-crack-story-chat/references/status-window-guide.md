# 상태창(HUD) 구성 가이드라인 (Status Window & HUD Guide)

크랙 스토리챗에서 상태창(코드블록 `Info`)은 단순한 UI 장식이 아닙니다. 모델의 컨텍스트 휘발성을 방어하는 **메모리 앵커(Memory Anchor)**이자, **씬 태깅(Scene Tagging) 및 상황 이미지 트리거 장치**입니다.

## 상태창의 3대 핵심 역할

1. **턴 간 연속성 계승 (Memory Continuity)**
   - 날짜, 시간, 현재 위치, 소지품, 신분, 관계도 등 매 턴 유지되어야 하는 상태값을 명시적으로 출력하여 다음 턴 모델의 컨텍스트 유실(치매 현상)을 방지합니다.
2. **상황 태깅 (Situation Tagging)**
   - 평온(`🟢`), 전투(`⚔️`), 키스(`💋`), 19+ 밀회(`♀🔞`/`♂🔞`) 등 현재 씬의 성격을 태깅하여, 다음 턴의 어조와 행동 양식을 즉시 동기화합니다.
3. **1줄 사실 요약 (Factual Recap)**
   - 추측이나 미사여구 없이, 이번 턴에서 **실제로 일어난 객관적 사실 1줄**만 기록하여 서사의 궤도를 유지합니다.

## 8대 표준 슬롯 규격

모든 상태창은 아래 8대 슬롯 중 프로젝트에 필요한 항목을 조합하여 구성합니다.

| 슬롯명 | 태그 | 기재 형식 및 규칙 |
|---|:---:|---|
| **1. 턴 & 발화** | `[🔈]` | `Tn ｜ ⚪` (기본) 또는 `[🔈] Tn ｜ 💬인물명` (마지막 발화자) |
| **2. 시간 축** | `[📅]` | `[연도/날짜] ｜ [AM/PM 시간]` (장면 내 소요 시간에 비례해 갱신) |
| **3. 공간 축** | `[📍]` | `[대지역명] > [세부 구역/장소명]` (이동 시 즉시 갱신) |
| **4. 유저 정보** | `[👤]` | `[소속/가문] ｜ [직책/신분] ｜ [등급/경지]` |
| **5. 현장 인물** | `[👥]` | `현장: 인물A(태도), 인물B(태도)` (현재 같은 공간에 있는 인물) |
| **6. 자원/장비** | `[🎒]` or `[⚔️]` | `소지품: [핵심아이템 1~2개]` 또는 `자원: 마력/체력 [N]%` |
| **7. 구분선** | `━━━` | 가로선 1줄 (`━━━━━━━━━━━━━━`) |
| **8. 상태/태그** | `[상태]` or `[분위기]` | `🟢안정 / ⚔️교전 / 💋스킨십 / ♀🔞밀회 / ⚠️경보` 등 |
| **9. 사실 요약** | `[상황]` | **이미 관찰된 객관적 사실 1줄** (예측/유도문 절대 금지) |

## ⚡ 캐릭터별 상태(`💋`) vs 시스템 전역 알럿(`🔞`)의 명확한 역할 분리

크랙 스토리챗에서는 **캐릭터에 대한 상호작용 상태**와 **키워드 감지를 위한 시스템 전역 알럿**의 위치와 역할을 명확히 분리합니다.

```
[관계]: 
 ㅤ▸ 서유진·'3급'·〈'담당 작전관'·💋〉  ← 💋: 특정 캐릭터에 대한 스킨십/키스 상호작용 상태
━
[상황]: "진료실 문 잠금, 서유진과 밀착" ｜ 🔞  ← 🔞: 키워드북(19+ 연출 모듈) 로드를 위한 '시스템 전역 알럿'
```

### 1. `[관계]` 슬롯: 공식 25종 관계 이모지 매트릭스 (Relationship Emoji Matrix)

상태창의 `[관계]` 슬롯은 인물별 호칭 뒤에 **공식 25종 관계 이모지**를 표기하여 인물 간의 심리적 거리, 감정 단계, 특수 관계를 1문자로 압축 유지합니다.

| 분류 | 이모지 | 공식 관계 명칭 | 심리적 거리 및 상호작용 상태 |
|:---:|:---:|---|---|
| **위험/사망** | `💀` | **사망+등장불가** | 사망하여 서사에서 영구 퇴장, 회상 외 등장 불가 |
| **적대/갈등** | `🤬` | **혐오** | 극단적 증오와 적대감, 살의 또는 절대적 거부 |
| | `😠` | **갈등** | 직접적인 대립, 의견/이해관계 충돌, 분노 |
| | `☹️` | **짜증·실망** | 마찰, 기대 이하의 실망, 뾰로통함, 불만족 |
| | `🤨` | **경계·의심** | 진의를 의심함, 탐색전, 방어 기제 작동 |
| **사무/중립** | `😐` | **일면식** | 안면만 튼 상태, 감정 교류 없음, 서먹함 |
| | `💼` | **업무관계** | 철저한 비즈니스/공식 파트너십, 공사 구분 |
| | `😑` | **중립·무관심** | 감정적 흥미 없음, 방관자적 태도 |
| **호감/우정** | `🙂` | **가벼운호감** | 긍정적인 첫인상, 편안한 일상 티키타카 |
| | `😀` | **뚜렷한호감** | 명확한 호의, 함께 있으면 즐거움, 적극적 대화 |

### 2. 캐릭터 세부 상태 슬롯 (피폐/구원/간호 씬 특화 규격)
히로인이나 주연 인물의 신체·정신 상태를 실시간 추적할 때 사용하는 고밀도 슬롯입니다:

1. **정신상태 (`[상태]`)**: 인물의 PTSD/트라우마 회복 곡선을 이모지와 단어로 반영
   - `🥀피폐` ➡️ `🌿안정` ➡️ `🌸회복` ➡️ `⚔️결연`
2. **복장 (`[복장]`)**: 단어 나열형으로 간결하게 표기 (문장형 설명/괄호 금지)
   - 예: `[복장]: 흰 셔츠, 갈색 가죽 스커트, 무릎 붕대`
3. **몸상태 (`[몸상태]`)**: 부상, 통증, 질병 증상을 짧은 단어로 기록 (ⓤ의 간호로 호전)
   - 예: `[몸상태]: 왼쪽 발목 염좌, 마력 역류 흔적, 미열`
4. **유저에 대한 인식 (`[인식]`)**: 상대방이 ⓤ를 어떻게 바라보는지 꺾쇠괄호 단어 조합으로 표기
   - 예: `[인식]: 「소중한 소꿉친구」`, `「마지막 안식처」`, `「나의 미래」`

### 3. 상태창 맨 끝 `[상황]` 슬롯: 키워드북 감지용 시스템 전역 알럿 (`🔰` ↔ `🔞`)
- **`🔰` (Safe 알럿)**: 평상시 모든 일반 장면(일상, 탐사, 전투, 정비 등). 키워드북의 성애 모듈 및 19+ CG 비활성.
- **`🔞` (19+ NSFW 알럿)**: 특정 캐릭터와 로맨스/스킨십이 심화되어 **다음 턴에 성적(19+) 장면이 전개될 조짐(전조)이 감지되는 즉시 `🔰` ➡️ `🔞`로 스위칭**.
  - 상태창 끝에 `🔞` 알럿이 뜨면, 시스템 키워드 엔진이 이를 감지하여 **다음 턴에 키워드북의 성애 연출 모듈(`성애_19금`)과 성인 체위(A01~A15) CG 규칙을 즉각 주입**합니다.
- **복귀**: 성애 씬이 종료되고 일상 구역으로 복귀하면 다시 `🔞` ➡️ `🔰`로 복귀.

## 상태창 갱신 및 계승 원칙

1. **코드블록 최하단 고정 출력**:
   - 매 응답의 맨 마지막에 반드시 ` ```Info ... ``` ` 형태로 출력합니다.
2. **직전 값 계승 (No Reset)**:
   - 본문에서 특별히 시간이 흐르거나 장소가 바뀌지 않았다면, 직전 턴의 `[📅]`, `[📍]`, `[👤]` 값을 그대로 유지합니다. 값이 안 적혔다고 해서 `미상`으로 초기화하지 않습니다.
3. **본문 확정 사실만 반영**:
   - ⓤ가 실제로 아이템을 획득하거나 마력을 소모했을 때만 `[🎒]` 수치를 갱신합니다.
4. **객관적 사실 요약 (`[상황]` 슬롯)**:
   - ❌ 잘못된 예: `"에스칼이 화가 난 것 같다. 사과할 것인가?"` (선택지 유도 및 심리 추측 금지)
   - ⭕ 올바른 예: `"연회장에서 에스칼이 와인잔을 내려놓으며 결투 신청 서한을 건넨 상태"` (객관적 팩트만)
