# 상세설명란 및 써머리 코멘트 가이드 (Story Description & Summary Comment)

크랙 플랫폼의 **스토리 상세설명란(Story Description)**과 **고정 댓글/목록용 요약(Summary Comment)**의 분리 작성 및 활용 가이드입니다.

크랙의 렌더링 환경에 따라 **마크다운이 지원되는 발행 화면(상세설명)**과 **마크다운 문법이 지원되지 않는 댓글/요약란(써머리 코멘트)**의 작성 서식을 분리하여 운영할 수 있습니다. (무조건 이렇게 해야 하는 강제 규격이 아니며, 프로젝트의 규모와 배포 채널의 필요에 따라 유연하게 선택·조합합니다.)

## 1. 렌더링 환경과 산출물 분리 전략

| 구분 | **상세설명 (`story-description.md`)** | **써머리 코멘트 (`summary-comment.md`)** |
|---|---|---|
| **반영 위치** | 크랙 발행 화면의 **상세 설명**란 | 크랙 작품 **고정 댓글** 또는 카드형 요약란 |
| **마크다운 파싱** | **지원됨 (Markdown O)** | **지원 안 됨 (Plain Text Only)** |
| **권장 서식** | `[![배너](URL)](URL)`, `| 표 |`, `##`, `---` | `■`, `▶`, `·`, `-`, 줄바꿈 등 유니코드 기호 |
| **핵심 목적** | 웹 쇼케이스 연결, 에셋 규모 증명, 제작 의도 전달 | 인물 번호 매핑 빠른 참조, 댓글창 프로필 대조 |

> 💡 **유연한 적용**: 외부 웹 쇼케이스 갤러리가 없거나 에셋이 적은 단편의 경우 배너/통계표를 생략할 수 있으며, 하나의 파일로 충분하다면 기존처럼 단일 코멘트로 운영해도 무방합니다.

## 2. 상세설명 (`build/assets/story-description.md` - Markdown O)

크랙 발행 화면의 상세설명란은 마크다운 문법을 완벽히 렌더링합니다.

### 구성 블록 1: 🌐 클릭형 배너 링크
외부 호스팅(Cloudflare Pages 등)의 웹 쇼케이스 갤러리로 플레이어를 유도하는 클릭 가능한 이미지 배너입니다.
```markdown
[![작품명](https://<project-name>.pages.dev/banner.png)](https://<project-name>.pages.dev/)
```

### 구성 블록 2: 📊 이미지 에셋 통계표
제작된 일러스트 장수와 구성을 한눈에 보여주어 플레이어에게 비주얼 완성도와 스케일을 입증합니다.
```markdown
## 📊 이미지 에셋 통계표

| 등장인물 | 🖼️ 일반 감정 | 🔞 성인 씬 |
| --- | ---: | ---: |
| ♀：10명 (이름·이름·...) | 인물당 18장 (S01~S18) | 인물당 15장 (A01~A15) |
| ♂：7명 (이름·이름·...) | 인물당 17장 (S01~S17) | - |
| **전체：17명** | **일반 299장** | **성인 150장 (총 449장)** |
```

### 구성 블록 3: 💬 제작자 코멘트
단순한 줄거리 요약이 아니라, **작품의 현실적 갈등 딜레마(비용, 부채, 상업적 압박, 생존 문제 등)**와 플레이어와의 소통 안내를 전달합니다.
```markdown
## 💬 제작자 코멘트

「제작자 코멘트」

[작품의 1~2줄 핵심 로그라인 및 플레이어 역할 소개]
[현실적 문제/딜레마: 대출, 월세, 실적, 계약 관계, 이해관계 충돌 등]

진행이 꼬이거나 설정 확인이 필요하면 `/OOC`로 편하게 말씀해 주세요.
플레이하시면서 개선 사항이나 건의사항은 언제든 댓글로 남겨주시면 빠르게 반영하겠습니다.

재밌게 즐겨주세요. 항상 감사합니다.
```

## 3. 써머리 코멘트 (`build/assets/summary-comment.md` - Plain Text Only)

크랙의 댓글창이나 일부 요약 카드는 마크다운 파서를 거치지 않고 **입력한 텍스트 그대로 노출**됩니다. 만약 여기에 `**볼드**`나 `### 헤딩`, `| 테이블 |`을 넣으면 서식이 깨진 채 기호가 노출되어 가독성이 심각하게 저하됩니다.

### 작성 원칙: 마크다운 문법 배제
- `**볼드**`, `*이탤릭*` ❌ → `[이름 01]` 또는 괄호/따옴표 활용
- `##`, `###` 마크다운 제목 ❌ → `■`, `▶`, `◆` 유니코드 기호 활용
- `| 헤더 | 열 |` 마크다운 테이블 ❌ → 줄바꿈 및 `·` 기호 정렬
- `[링크](URL)` ❌ → 순수 URL 표기 또는 생략

### 👥 캐릭터 소개 및 번호 매핑
댓글창에서 플레이어가 등장인물들의 번호, 소속, 나이, MBTI, 역할을 즉시 찾아볼 수 있도록 정리합니다.
```text
■ 캐릭터 소개

▶ [소속/진영/역할군 1]
- 한지수 01 · 주간 알바 / 대학생 · 21세 · ESFJ / 2w3 — 성실하고 눈치 빠른 상식의 수호자. 뭘 목격해도 상식으로 억지 납득함.
- 연화 02 · 지박령 / 선주민 · 20대 초 외견 · ENTP / 7w6 — 편의점 와이파이와 신상 젤리를 누리며 계산대 안쪽에 상주하는 인터넷 중독 지박령.

▶ [소속/진영/역할군 2]
- 미호 03 · 구미호 / 백수 단골 · 20대 중 외견 · ESTP / 3w2 — 능글맞은 반말과 허세로 무장했으나 연애 경험 0인 순정 여우.
- 에리 04 · 호문쿨루스 · 20대 초 외견 · INTP / 5w6 — 악의 없이 가장 곤란한 팩트와 수치를 정확히 짚어내는 측정광.
```

```markdown
| ♂：7명 (우치·벨·강태오·아그니르·도현우·백준서·강림) | 인물당 17장 (S01~S17) | - |
| **전체：17명** | **일반 299장** | **성인 150장 (총 449장)** |

## 💬 제작자 코멘트

「제작자 코멘트」

역세권·주거지·상업지가 겹치는 완벽한 목에 영끌 대출 1억 2천을 얹어 편의점을 차렸습니다.
상권 분석은 완벽했는데, 그 자리 밑에서 영맥·황천길·영혼이동로·마력·생명력이 교차한다는 건 계약서에 없었습니다.

구미호는 연애 경험 0을 허세로 덮고, 고대 드래곤은 100원 손해와 2+1 행사에 목숨을 걸며, 천사와 악마는 실적과 규정으로 싸우고, 뱀파이어는 코인/선물 레버리지로 돈을 날립니다. 늑대인간은 야간 상하차를 뛰다 다쳐도 인간 병원에 못 가 야간 동물병원에 외상값을 쌓습니다.

세계관은 판타지지만 문제는 전부 지극히 현실적인 생활입니다.
대출과 월세 780만 원은 사라지지 않으며, 손해는 협상하지 않으면 고스란히 점주가 뒤집어씁니다.

진행이 꼬이거나 설정 확인이 필요하면 `/OOC`로 편하게 말씀해 주세요.
플레이하시면서 개선 사항이나 건의사항은 언제든 댓글로 남겨주시면 빠르게 반영하겠습니다.

재밌게 즐겨주세요. 항상 감사합니다.
```

```text
■ 캐릭터 소개

▶ 상주 및 매장 근무
- 한지수 01 · 주간 알바 / 대학생 · 21세 · ESFJ / 2w3 — 성실하고 눈치 빠른 상식의 수호자. 뭘 목격해도 상식으로 억지 납득함.
- 연화 02 · 지박령 / 선주민 · 20대 초 외견 · ENTP / 7w6 — 편의점 와이파이와 신상 젤리를 누리며 계산대 안쪽에 상주하는 인터넷 중독 지박령.

▶ 단골 초자연 손님들 (여성)
- 미호 03 · 구미호 / 백수 단골 · 20대 중 외견 · ESTP / 3w2 — 능글맞은 반말과 허세로 무장했으나 연애 경험 0인 순정 여우.
- 에리 04 · 호문쿨루스 · 20대 초 외견 · INTP / 5w6 — 악의 없이 가장 곤란한 팩트와 수치를 정확히 짚어내는 측정광.
- 한세라 05 · 인간 / 연금술 박사과정 · 27세 · INTP / 5w4 — 생명 창조는 성공했으나 논문 통과와 졸업을 못 해 찌든 만성피로 연구원.
- 루시엘 06 · 천사 / 천계 영혼관리부 · 20대 후 외견 · ISTJ / 1w9 — 신성함보다 규정과 공무원 연금을 중시하며 날개 크기로 감정을 누설하는 원칙주의자.
- 카밀라 07 · 뱀파이어 / 직장인 · 20대 후 외견 · INTJ / 5w6 — 지적이고 차분하지만 고위험 투자만 손대면 "이번엔 달라요"를 외치는 자칭 투자의 귀재.
- 아녜스 08 · 인간 / 현역 성녀 · 28세 · ESFP / 8w7 — 공식에선 자애로운 성녀, 퇴근 후 사석에선 거친 입담과 술부터 찾는 현실 누나.
- 윤하린 09 · 인간 / 성인 마법소녀 · 25세 · ISFP / 6w7 — 10년 장기복무 번아웃에 찌들어 뒷문에서 담배를 태우는 베테랑 마법소녀.
```
