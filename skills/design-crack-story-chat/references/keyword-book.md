# 키워드북 설계 가이드 (Keyword Book Architecture & Trigger Modules)

다섯 번째 산출물인 `build/keyword-book.md`는 크랙 플랫폼의 **키워드북(Keyword Book)** 탭과 **단축어(Shortcuts)** 탭에 등록할 항목들을 정의합니다.

상시 시스템 프롬프트(7,000자 상한)를 가볍게 유지하면서, 특정 상황(키스, 19+ 성애, 특수 전투, 정치 암투 등)이 발생했을 때만 **3슬롯 런타임 주입**을 통해 연출 밀도를 극대화하는 **트리거 모듈 분리 패턴(Trigger-Module Separation)**의 핵심 문서입니다.

## 1. 3슬롯 런타임 메커니즘과 설계 원칙

1. **상시 프롬프트 토큰 절약**: 키스/체위/전투 등 고밀도 지침을 메인 프롬프트에 넣으면 토큰이 고갈되고 일상 씬이 오염됩니다. 키워드북으로 분리하여 평상시 0토큰을 유지합니다.
2. **동시 활성화 최대 3개 한도**: 크랙 엔진은 턴당 최대 3개의 키워드북 항목만 프롬프트 최상단에 주입합니다. 4개 이상 매칭 시 우선순위가 낮은 항목이 드랍(Drop)되므로, 키워드 중복을 최소화합니다.
3. **항목당 400자 엄수**: 크랙 UI 입력창 한도(400자) 및 주입 오버헤드 방지를 위해 항목당 본문은 **300~380자 내외**로 작성합니다.

## 2. 핵심 4대 연출 트리거 모듈

### 모듈 1: 키스 / 스킨십 연출 (`kb.directive_kiss`)
```markdown
# `kb.directive_kiss` — 연출_키스스킨십
- activation_setting: 전체 시작 설정
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [💋, 키스, 뽀뽀, 입맞춤, 스킨십]

## Entry text
[키스/스킨십 연출 지침]
-효과음(*text*)을 ⓒ 대사 중간에 삽입하고, 입술 물기·혀 빨기·타액·호흡 섞임 등 구체적 감각 묘사
-입 막힘/혀 삽입으로 인한 발음 뭉개짐(어눌한 대사) 적극 표현
-접촉 강도 변화에 따른 신체 떨림·손의 위치·가빠지는 호흡 묘사
-감정을 직접 단정하지 않고 신체 반응과 호흡으로 간접 표현
-ⓤ의 내면 심리는 쓰지 말고, 외적 호흡/반응에 맞춘 ⓒ의 반응으로 전개
```

### 모듈 2: 성애 / 19+ 묘사 (`kb.directive_nsfw`)

성애 연출 모듈은 **5대 설계 기둥(주도권 보장, 감각적 밀도, 앵커링, 사후 여운, A코드 이미지 바인딩)**을 바탕으로 작성됩니다.

#### 🏛️ 19+ 성애 연출 모듈의 5대 설계 기둥
1. **플레이어 주도권 & 상호 동의 (Agency & Consent)**: 상태창 `[상황]` 끝자리에 `[🔞]` 신호를 띄워 전조를 알리되, AI가 본문에서 성행위를 강제 시작하지 않음. 실제 진입은 플레이어(ⓤ)가 결정. 거절/침묵 시 ⓒ는 즉시 물러남.
2. **신체적·감각적 정밀 묘사 (Somatic & Sensory Density)**: 피부 마찰, 체온, 숨소리, 신음, 타액, 떨림, 시선 등 구체적 감각 서술. 감정을 형용사로 단정하지 않고 신체 반응으로 표현.
3. **오프닝 앵커링 분량 제어 (Length Clamping)**: 성인 장면이라도 서술량이 폭증하지 않도록 세션 첫 응답의 분량 기준선 준수.
4. **절정과 사후 여운 (Aftercare & Pillow Talk)**: 절정 후 나른한 대화, 체온의 잔향, 정서적 유대감 반영.
5. **성인 체위 이미지(A01~A15) 동적 호출**: UNSAFE 모드에서 🔞 활성화 시 체위 전환 대사 직전에 A코드 이미지 호출.

#### 📐 표준 완성형 템플릿 (권장, ≤400자)
```markdown
# `kb.directive_nsfw` — 연출_성애묘사
- activation_setting: 전체 시작 설정
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [🔞, 섹스, 애무, 합방, 체위]

## Entry text
UNSAFE 성인 이미지(🔞 뒤에만)=A01정상위 A02후배위 A03기승위 A04들박 A05핸드잡 A06펠라 A07딥쓰롯 A08파이즈리 A09풋잡 A10커널링구스 A11핸드잡·가슴 A12가슴 A13프렌치키스 A14필로우토크 A15핑거링. 01~11만 보유. 그 외엔 S 코드.

[성애/19+ 연출 지침]
-접촉·체온·숨소리·마찰 등 신체적 감각 중심 서술. 감정은 단정치 않고 떨림·시선·호흡으로 묘사
-체위 전환 시 대사 직전에 해당 A코드 1회 호출
-ⓒ는 현재 단계까지만 시도하며, ⓤ의 거절·침묵 시 즉시 물러남. 🔞 최종 진입은 ⓤ가 결정
-절정 후 필로우토크와 나른한 여운, 정서적 유대감 반영. 서술 분량 급상승 금지
```

#### 🎭 프로젝트 톤앤매너별 변주 예시 (선택 적용)
* **변주 A: 긴장감/거리감 절제형 (Atmospheric / Slow Tension)**
  > "거리부터 쓴다. 닿는 간격, 닫힌 문, 복도의 소리. 감정을 이름으로 부르지 말고 멈춘 손·늦어진 대답·피한 눈으로. ⓒ는 현재 단계에서 가능한 데까지만 하고 멈춘다. 재촉×, 거절·침묵 시 물러난다. 고백은 새어 나온 문장으로. 🔞 조건이 차면 상태창에 띄우되 진입은 ⓤ가 한다."
* **변주 B: 직접적 신체/감각 집중형 (Visceral / Sensory Heavy)**
  > "피부의 마찰열, 젖은 소리와 혀의 섞임, 닿는 체온에 집중. 체위 변화마다 신체 반동과 결합감 묘사. 대사 사이에 헐떡이는 호흡과 신음 삽입. 사후 땀방울과 엉킨 시트의 여운 묘사."

### 모듈 3: 특수 전투 / 결전 연출 (`kb.directive_combat`)
```markdown
# `kb.directive_combat` — 연출_특수전투
- activation_setting: 전체 시작 설정
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [전투, 결투, 교전, 극한전투, 각성]

## Entry text
[전투 연출 지침]
-단문(Short-sentence) 중심의 속도감 있는 공방 서술
-합(合) 단위 공방 묘사: 공격→방어→반격의 인과관계 명확화
-무기 타격감, 충격파, 크롬/마력 과열 등 물리적 감각 묘사
-전투 결과는 ⓤ가 직접 선언하게 두고, AI는 빗맞음·방어·상황 압력까지만 서술
-ⓤ가 전투 회피/일탈 선언 시 교전 조기 종결 후 이탈 허용
```

## 3. 항목 스키마 및 작성 한도 규격

다섯 번째 산출물인 `build/keyword-book.md`는 아래 헤딩 규격을 엄격히 준수합니다 (`check_keyword_book.py` 검증 대상):

```markdown
# `kb.[ID]` — 항목명
- activation_setting: 전체 시작 설정 (또는 특정 시작설정 이름)
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [키워드1, 키워드2, 키워드3]

## Entry text
[크랙 UI 본문 칸에 넣을 정확한 문자열; ≤400자]
```

## 4. 단축어(Shortcuts) 등록 규격

단축어는 키워드북과 동일한 물리 파일(`build/keyword-book.md`)의 하단 섹션으로 관리하되, UI에는 별도 단축어 탭에 등록합니다 (최대 20개, 이름 ≤10자, 설명 ≤30자, 프롬프트 ≤400자).

```markdown
# Shortcut `summary`
- name: 요약
- description: 최근 공개 사건 압축 요약
- prompt: 지금까지 일어난 주요 사건, 현재 위치, 각 인물과의 핵심 관계 변화를 3줄 이내의 불릿 포인트로 간결하게 요약해 줘.

# Shortcut `status_check`
- name: 상태점검
- description: 현재 인물들의 심리와 호감도 점검
- prompt: 현재 현장에 있는 주연 인물들이 주인공(나)을 바라보는 속마음과 무의식적인 경계/호감 상태를 관찰자 시점에서 1줄씩 브리핑해 줘.
```
