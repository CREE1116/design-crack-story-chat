## 역할과 예산 경계

키워드북은 사용자 메시지나 모델 출력에서 등록 키워드를 감지하고, 해당 항목이 활성화 조건을 만족할 때 **다음 출력의 프롬프트에 본문을 동적으로 삽입하는 조건부 컨텍스트**입니다.

- **규격**: 1개 항목당 `이름 ≤ 20자` + `적용 시작설정` + `키워드 1~5개 (각 ≤ 10자)` + `본문 ≤ 400자`
- **동시 활성 상한**: 한 번에 최대 **3개 항목**만 로드됩니다. (3슬롯 한계)
- **작품당 상한**: 최대 20개 항목 등록 가능.

---

## 키워드북은 단순 백과사전이 아니다 (트리거 연출 모듈화)

키워드북의 가장 중요한 실전 용도는 설정 조회가 아니라 **"평소에는 꺼두고 특정 씬에서만 켜는 고밀도 연출 모듈(Trigger Directives)"**입니다.

- **통합본에 두면 안 되는 이유**: 키스, 성애(19+), 특수 전투 연출 지침을 메인 프롬프트(7,000자)에 넣으면 토큰을 낭비하고 일상 씬의 출력을 오염시킵니다.
- **키워드북에 분리하는 이유**: 관련 키워드가 감지될 때만 400자짜리 전문 연출 지침이 3슬롯 중 하나로 주입되어, 평상시에는 맑은 일상 톤을 유지하고 위기/특수 씬에서는 폭발적인 연출력을 발휘합니다.

## 표준 트리거 연출 모듈 4종

실전에서 즉시 사용할 수 있는 4대 표준 트리거 연출 모듈입니다.

### 1. 키스 / 스킨십 연출 모듈
```markdown
# `kb.directive_kiss` — 연출_키스스킨십
- activation_setting: 전체 시작 설정
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [💋, 키스, 뽀뽀, 입맞춤, 스킨십]

## Entry text
[키스/스킨십 연출 지침]
-효과음(*text*)을 ⓒ 대사 중간에 삽입
-입술 물기, 혀 빨기, 입천장 자극 등 구체적 테크닉과 혀 섞임 묘사
-입 막힘/혀 삽입으로 인한 발음 뭉개짐(어눌한 발음) 적극 표현
-쾌감·흥분 극대화를 위한 감각적 과장 허용, 입/숨소리 강조
-접촉 강도 변화에 따른 신체 떨림·손 위치·호흡 변화 묘사
-ⓤ의 내면 감정은 쓰지 말고 외적 호흡/반응에 맞춘 ⓒ의 반응으로 유도
```

### 2. 성애 / 19+ 묘사 모듈
```markdown
# `kb.directive_nsfw` — 연출_성애묘사
- activation_setting: 전체 시작 설정
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [🔞, 섹스, 애무, 합방, 체위]

## Entry text
[성애/19+ 연출 지침]
-삽입/애무/체위(정상위·기승위·후배위 등)의 구체적 동작과 마찰음·체온 묘사
-대사 사이 거친 숨소리와 신음 효과음 삽입
-상태창 최하단에 현재 체위 및 19+ 상황 태깅(♀🔞/♂🔞) 반영
-사후 나른한 대화와 땀, 여운의 감정선(SlowBurn) 묘사
-주의: 성적 장면이라도 서술 분량 급상승 금지(오프닝 앵커링 준수)
-ⓤ의 신체 감각을 강제 단정하지 말고 ⓒ의 주도적 애무와 반응으로 전개
```

### 3. 특수 전투 / 결전 연출 모듈
```markdown
# `kb.directive_combat` — 연출_특수전투
- activation_setting: 전체 시작 설정
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [전투, 결투, 교전, 오버라이드, 각성]

## Entry text
[전투 연출 지침]
-단문(Short-sentence) 중심의 속도감 있는 공방 서술
-합(合) 단위 공방 묘사: 공격→방어→반격의 인과관계 명확화
-무기 타격감, 충격파, 크롬/마력 과열 등 물리적 감각 묘사
-전투 결과는 ⓤ가 직접 선언하게 두고, AI는 빗맞음·방어·상황 압력까지만 서술
-ⓤ가 전투 회피/일탈 선언 시 교전 조기 종결 후 이탈 허용
```

### 4. 심화 사교 / 정치 암투 모듈
```markdown
# `kb.directive_politics` — 사교_명가정치
- activation_setting: 전체 시작 설정
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [사교계, 가십, 연회, 황실, 명가]

## Entry text
[사교/정치 연출 지침]
-우아한 격식체 이면에 숨겨진 날 선 탐색과 눈치 싸움 묘사
-가문 간 서열/이해관계에 따른 미묘한 시선 처리와 헛기침, 미소 뒤의 계산 서술
-소문과 가십을 활용해 자연스러운 주변 인물들의 수군거림 배경음 처리
-직접적 공격 대신 평판, 혼담, 뒷공작을 통한 외교적 압박 연출
```

## 항목 스키마와 최종 등록표 규격

다섯 번째 산출물인 `build/keyword-book.md`는 아래 헤딩 규격을 엄격히 준수합니다 (`check_keyword_book.py` 검증 대상):

```markdown
# `kb.[ID]` — 항목명
- activation_setting: 전체 시작 설정 (또는 특정 시작설정 이름)
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [키워드1, 키워드2, 키워드3]

## Entry text
[크랙 UI 본문 칸에 넣을 정확한 문자열; ≤400자]
```

## 단축어(Shortcuts) 등록 규격

단축어는 키워드북과 동일한 물리 파일(`build/keyword-book.md`)의 하단 섹션으로 관리하되, UI에는 별도 단축어 탭에 등록합니다 (최대 20개, 이름 ≤10자, 설명 ≤30자, 프롬프트 ≤400자).

```markdown
# Shortcut `summary`
- name: 요약
- description: 최근 공개 사건 압축 요약

## Shortcut prompt
[최근 3턴 간의 대화에서 공개·확정된 핵심 사실과 현재 인물 위치를 3줄 이내로 압축 요약하라. 미공개 비밀이나 추론은 포함하지 않는다.]
```

## 트리거 설계 및 3슬롯 경합 관리

- **키워드 수**: 항목당 1~5개 (10자 이하 단어)
- **적정 특이도**: 너무 흔한 단어(`사람`, `힘`)나 너무 긴 문장 배제.
- **3슬롯 경합 대책**:
  - 한 장면에 3개 이상의 항목이 경합할 때 등록표 위쪽 항목이 우선됩니다.
  - 중요한 연출 모듈과 핵심 인물을 위쪽에 배치하고, 일반 조회성 설정은 중간, 채움형 지침은 맨 아래에 배치합니다.
  - 탈락하더라도 씬이 깨지지 않도록 최소한의 불변식(1줄 인물 명부 등)은 통합 프롬프트에 둡니다.

## 지식 범위와 비밀 공개

- 비밀을 상시 로드한 뒤 "말하지 말라"고 지시하지 않습니다.
- 비밀 단서는 희귀한 고유 키워드와 결합된 키워드북 항목으로 격리하여, 플레이어가 실제로 해당 단서를 발견했을 때만 로드되도록 설계합니다.
