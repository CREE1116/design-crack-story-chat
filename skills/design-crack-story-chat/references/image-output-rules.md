# 이미지 출력 규칙

이미지를 쓰는 작품에만 적용한다. **실제 배포 자산의 닫힌 목록**을 기준으로 호출하며 이미지가 없거나 적합하지 않아도 본문은 진행한다. 코드명·대상 인물·URL은 작품마다 다르며 특정 번호·성별·인원수를 표준으로 가정하지 않는다.

## 1. 메인에 넣을 최소 계약

아래 `{{...}}`를 실제 자산으로 채운다. 이미지 경로를 확정하기 전에는 예시 URL을 최종 프롬프트에 넣지 않는다.

```text
이미지:{{배포 URL과 경로 형식}};허용 인물·상황={{실제 등록 목록 또는 압축 매핑}}.
호출=첫 등장·상황/감정 변화 중 새 이미지가 필요한 때,관련 대사 바로 위에 1장. 동일 이미지 반복×.
현재 장면과 일치하는 등록 자산만 사용;없는 번호·경로 추정×. 적합한 자산이 없으면 이미지 줄만 생략하고 본문 진행.
```

빈도는 작품의 출력 계약에 맞춰 바꿀 수 있다. 이미지 호출을 위해 NPC 발화·감정 변화·장면 전환을 만들어내지 않는다. 인물 이미지는 인물 경로, 배경 이미지는 배경 경로에 연결하며 둘을 혼용하지 않는다.

## 2. 상황별 코드와 키워드북

항상 쓰는 최소 경로·일반 코드 목록은 메인에, 조건부 자산 상세는 관련 키워드북에 둔다. `S01/A01` 같은 명칭은 선택 가능한 관례이며 실제 파일명이 우선한다. 성인 전용 코드·자산은 unsafe 키워드북에서만 정의하고 SAFE에는 포함하지 않는다. 존재하지 않는 매트릭스를 채우려고 이미지를 가정하지 않는다.

키워드북은 직전 모델 발화+현재 유저 발화로 발동한다. 현재 유저 입력으로 관련 항목이 이미 활성화됐다면 그 응답에 사용할 수 있다. 호출 표식을 띄우려고 의무적으로 한 턴 대기시키지 않는다. 항목 누락 시 이미지를 생략하며 장면·관계 진전은 해당 서사 규칙으로 처리한다.

등록 형식·슬롯 우선순위·트리거는 [keyword-book.md](keyword-book.md)를 따른다. 이미지 코드 목록에 별도 관계 단계 해금 규칙이나 연출 엔진을 덧붙이지 않는다.

## 3. 자산과 출력 검증

- URL·확장자·대소문자·인물/상황 조합을 실제 파일 목록과 대조한다.
- 키워드북에만 있는 코드가 비활성 상태에서 만들어지지 않는지 확인한다.
- 대상 이미지 없음·같은 이미지 반복·한 장면 여러 인물·배경 전환을 대입한다.
- 이미지가 누락돼도 ⓤ 선택·본문·확정 관계가 유지되는지 확인한다.

배포·변환은 [image-assets.md](image-assets.md), 대사·지문·HUD 결합은 [output-contract.md](output-contract.md)가 소유한다. 코드·태그 사전은 실제 제작에 필요할 때 [novelai-prompt-engineering.md](novelai-prompt-engineering.md)를 참고한다.
