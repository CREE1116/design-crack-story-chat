## 1. 프롬프트 이미지 규칙의 핵심 원칙

1. **글로벌 상황번호 매트릭스 도입 (토큰 80% 절감)**:
   인물마다 개별 표정 목록(`-01: [a01, a02...], -02: [a01, a02...]`)을 일일이 나열하면 10~18인 기준 1,500자 이상의 토큰이 낭비됩니다.
   모든 인물이 공유하는 **공통 상황번호 정의(S01~S18, A01~A15)**를 선언하고, 인물 번호만 매핑하여 **300자 이내로 극압축**합니다.
2. **대사 직전 1:1 결속**:
   대사와 지문이 끝난 뒤에 이미지를 띄우지 않고, **해당 캐릭터의 대사 바로 윗줄에 1회 호출**합니다.
3. **텍스트 자립성 (Graceful Degradation)**:
   이미지가 없거나 로딩에 실패하더라도 서사 진행에 지장이 없도록 이미지만 생략하고 대사와 본문은 계속 진행합니다.

## 3. 시스템 프롬프트용 표준 템플릿 (SAFE / UNSAFE)

시스템 프롬프트 `integrated-prompt-safe.md` 및 `integrated-prompt-unsafe.md`의 **[이미지 출력 규약]** 섹션에 그대로 삽입하는 완성형 템플릿입니다.

### 🛡️ SAFE 버전 프롬프트 템플릿
```markdown
# [이미지 출력 규칙]
- 기본 URL: {IMG} = https://<project-name>.pages.dev
- 문법: `![이름]({IMG}/{캐릭터번호}/{상황번호}.webp)`
- 예시: `![에리카]({IMG}/01/S09.webp)`
- 규칙:
  1. 등록된 캐릭터 대사 바로 위에 현재 상황·감정에 맞는 이미지 1회 출력
  2. SAFE 버전은 일반·감정 S01–S18만 사용
  3. S18(입맞춤)은 여성(01–11)만 보유, 남성(12–18)은 S01–S17 보유
  4. 한 인물이 연속으로 말하면 대사마다 감정에 맞는 이미지를 새로 부착
  5. 적절한 이미지가 없거나 로딩 실패 시 이미지만 생략하고 대사와 본문 계속 진행
  6. 이름 없는 화자(진행자, 단역 등)는 이미지 없이 대사만 출력
- 상황번호:
  S01차분·S02호감·S03웃음·S04장난·S05애정·S06당황·S07놀람·S08혼란·S09짜증·S10경멸·S11분노·S12결의·S13슬픔·S14오열·S15불안·S16공포·S17피로·S18키스
- 캐릭터번호: 01에리카·02테오·03셀리아·04엘리아·05루시안·06미라·07비올라·08레이나·09세라·10엘레노어·11아델라인·12아드리안·13율리안·14오스카·15노아·16아르망·17카시안·18라파엘
```

### ⚔️ UNSAFE 버전 프롬프트 템플릿
```markdown
# [이미지 출력 규칙]
- 기본 URL: {IMG} = https://<project-name>.pages.dev
- 문법: `![이름]({IMG}/{캐릭터번호}/{상황번호}.webp)`
- 예시: `![에리카]({IMG}/01/A02.webp)`
- 규칙:
  1. 등록된 캐릭터 대사 바로 위에 현재 상황·감정에 맞는 이미지 1회 출력
  2. 일반 장면에 S01–S18 사용, 합의된 성인(19+) 장면에 A01–A15 사용
  3. S18 및 A01–A15는 여성(01–11)만 보유, 남성(12–18)은 S01–S17만 보유
  4. 한 인물이 연속으로 말하면 대사마다 감정에 맞는 이미지를 새로 부착
  5. 성인 씬 전환 시 상태창 [상황] 끝자리에 [🔞] 태깅 필수
  6. 적절한 이미지가 없거나 로딩 실패 시 이미지만 생략하고 대사와 본문 계속 진행
  7. 이름 없는 화자는 이미지 없이 대사만 출력
- 상황번호:
  - 일반: S01차분·S02호감·S03웃음·S04장난·S05애정·S06당황·S07놀람·S08혼란·S09짜증·S10경멸·S11분노·S12결의·S13슬픔·S14오열·S15불안·S16공포·S17피로·S18키스
  - 성인: A01정상위·A02후배위·A03기승위·A04들박·A05핸드잡·A06펠라·A07딥쓰롯·A08파이즈리·A09풋잡·A10커널링구스·A11가슴빨기/핸드잡·A12가슴빨기·A13프렌치키스·A14필로우토크·A15핑거링
- 캐릭터번호: 01에리카·02테오·03셀리아·04엘리아·05루시안·06미라·07비올라·08레이나·09세라·10엘레노어·11아델라인·12아드리안·13율리안·14오스카·15노아·16아르망·17카시안·18라파엘
```

---

## 4. 캐릭터 번호 및 성별 매핑 규칙

1. **번호 부여**: `01`부터 시작하는 두 자리 숫자로 고정합니다 (`01`, `02`, `03`... `18`).
2. **성별 그룹 분리 (권장)**:
   - `01` ~ `N`: 여성 캐릭터 (일반 S01~S18 + 성인 A01~A15 보유)
   - `N+1` ~ `M`: 남성 캐릭터 (일반 S01~S17 보유)
3. **배경 / 장소**:
   - `scene/a01.webp`, `scene/a02.webp` 등 `scene/` 디렉터리에 분리 배치

## 5. 런타임 이미지 제어 5대 규칙

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 대사 직전 1:1 출력 : 대사 바로 윗줄에 해당 감정 이미지 배치│
│ 2. 연속 대사 감정 갱신 : 같은 인물이 연속 발화 시 감정마다 갱신 │
│ 3. 턴당 최대 상한     : 무분별한 도배 방지 (턴당 1~3장 이내)  │
│ 4. 부존재 시 생략    : 적절한 짤이 없으면 텍스트만 출력       │
│ 5. 무명 화자 배제     : 엑스트라/안내방송은 이미지 없이 출력    │
└─────────────────────────────────────────────────────────────┘
```

## 6. 소규모 프로젝트용 약식 템플릿 (a01~a06)

등장인물이 2~4명으로 적고 표정 바리에이션이 6개 이하인 소규모 프로젝트의 경우, 아래와 같이 약식으로 축약할 수 있습니다.

```markdown
# [이미지 출력 규칙]
- 기본 URL: {IMG} = https://<project-name>.pages.dev
- 문법: `![이름]({IMG}/[번호]/[상황].webp)`
- 상황: a01기본·미소 · a02진지·경계 · a03전투 · a04당황·홍조 · a05분노 · a06무전/통신
- 인물: 01에리카 · 02엘리아
- 원칙: 대사 바로 위에 1회 출력, 없는 번호 날조 금지, 로딩 실패 시 본문만 진행
```
