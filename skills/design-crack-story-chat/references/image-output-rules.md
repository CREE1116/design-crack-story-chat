## 역할과 아키텍처

크랙 스토리챗은 마크다운 이미지 태그(`![](URL)`)를 통해 **Cloudflare Pages**에 호스팅된 고압축 **WebP** 이미지를 대화 중간에 실시간으로 호출합니다.

- **[image-assets.md](image-assets.md)**: 이미지를 WebP로 변환하고, Cloudflare Pages로 호스팅하며, 쇼케이스 웹페이지(`index.html`)를 제작하는 방법
- **[image-output-rules.md](image-output-rules.md) (본 문서)**: 만들어진 이미지를 시스템 프롬프트에서 **어떤 양식으로 정의하고 언제 출력할 것인가 (출력 규약 & 런타임 제어)**

## 표준 번호화 및 a/s 접두사 URL 스키마

프롬프트 토큰을 절약하고 안전/성인 씬을 명확히 구분하기 위해 **인물 번호화 + `a/s` 접두사 + WebP 포맷**을 표준으로 사용합니다.

```
{base}/{id}/{접두사}{번호}.webp
```

### 1. 카테고리/인물 번호 (`{id}`)
- 인물은 2자리(또는 1자리) 숫자로 치환: `01`, `02`, `03`...
- 고정 축: `scene/`(장소), `mob/`(몬스터), `event/`(이벤트)

### 2. 안전/성인 접두사 규약 (`a` vs `s`)
- **`a` (All / Safe / 일반)**: 전연령 안전한 일반 표정, 대화, 전투, 부상, 일상 등
  - 예: `01/a01.webp` (01번 인물 기본 평상)
  - 예: `01/a02.webp` (01번 인물 진지/경계)
  - 예: `01/a03.webp` (01번 인물 전투)
  - 예: `scene/a01.webp` (장소 배경)
- **`s` (Sex / NSFW / 성인)**: 성적 묘사, 애무, 합방, 체위, 절정 등 19+ 특수 씬
  - 예: `01/s01.webp` (01번 인물 합방 애무)
  - 예: `01/s02.webp` (01번 인물 정상위)
  - 예: `01/s03.webp` (01번 인물 절정/여운)

## 시스템 프롬프트 내 1줄 번호 매핑

통합 시스템 프롬프트(7,000자 상한) 안에서는 토큰을 아끼기 위해 긴 URL을 매번 반복하지 않고, **베이스 URL 매크로(`{IMG}`)와 1인 1줄 번호 매핑**으로 극압축합니다.

### 📐 상시 시스템 프롬프트 미디어 룰 (일반 a 시리즈 중심)
```markdown
# [이미지 출력 규칙]
-기본URL: {IMG} = https://<project-name>.pages.dev
-문법: `![]({IMG}/[ID]/[파일명].webp)`
-원칙: 공간 이동 시 상단 1회, 인물 대사 직전 1회, 동일 인물 연속 출력 금지, 턴당 최대 2장 제한
-장소: [scene/a01:광장, scene/a02:암시장, scene/a21:폐허]
-몬스터: [mob/a31:스카우트, mob/a32:3급아머트론]
-01_에리카: [a01:기본·미소, a02:비웃음, a03:진지·살벌, a04:당황, a05:부끄러움, a06:전투]
-02_엘리아: [a01:기본·단정, a02:경계, a03:통신·다급, a04:홍조, a05:화남, a06:무전]
```

## 키워드북 19+ 성애(s) 분리 패턴

성적 문제가 되는 **`s` 접두사 19+ 성애/체위 이미지**는 상시 프롬프트에 넣지 않고, [keyword-book.md](keyword-book.md)의 **성애 연출 모듈**로 분리합니다.

### 📐 키워드북 내 `s` 시리즈 19+ 이미지 매핑 예시
```markdown
# `kb.directive_nsfw` — 연출_성애묘사
- activation_setting: 전체 시작 설정
- activation_when: 사용자 메시지 또는 모델 출력에 키워드가 감지될 때
- keywords: [🔞, 섹스, 애무, 합방, 체위]

## Entry text
[성애 연출 및 19+ 이미지 지침]
-성애 CG: `![]({IMG}/[ID]/s[번호].webp)`
 -01_에리카: [s01:애무, s02:정상위, s03:후배위, s04:절정, s05:사후여운]
 -02_엘리아: [s01:키스, s02:기승위, s03:절정, s04:나른함]
-체위가 전환될 때 해당 대사 직전에 1회 호출
-상태창에 체위 및 [🔞특수밀회] 상태 태깅 필수
```

## 출력 타이밍 및 스로틀링 4대 원칙

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 장소 이미지 : 씬/공간 전환 시 응답 맨 위에 단 1회         │
│ 2. 인물 이미지 : 화자 전환 또는 강한 감정 변화 시 대사 직전 1회 │
│ 3. 중복 출력 금지: 한 턴에 같은 인물 이미지 2장 이상 연속 금지 │
│ 4. 턴당 총량 제한: 1개 응답당 최대 2장 이내 (장소1+인물1 등)  │
└─────────────────────────────────────────────────────────────┘
```

1. **장소 (`scene/a01.webp`)**: 공간이 바뀌거나 씬이 시작될 때 응답 최상단에 1회만 출력 (장소 유지 시 생략)
2. **인물 (`01/a01.webp`)**: 해당 캐릭터의 대사 바로 윗줄에 1회 출력
3. **동일 인물 연속 출력 금지**: 한 턴에 같은 인물의 표정 짤을 2장 이상 연속 출력 금지
4. **턴당 최대 2장 상한**: 모바일 화면 스크롤 폭발 방지를 위해 턴당 최대 2장으로 클램프

---

## 안전성 및 예외 처리 원칙

1. **환각 번호 생성 절대 금지**: 목록에 정의되지 않은 번호(예: `01/a99.webp`)를 모델이 임의로 생성하는 것을 엄격히 차단합니다. 적절한 표정이 없으면 이미지를 생략합니다.
2. **전체 WebP 포맷 통일**: `.png`, `.jpg` 대신 반드시 고압축 `.webp` 확장자만 호출합니다.
3. **텍스트 자립성 (Text Independence)**: 이미지가 로드되지 않더라도 텍스트 지문과 대사만으로 모든 상황이 완벽히 전달되어야 합니다.

## 실전 시스템 프롬프트 미디어 룰 템플릿

```markdown
# [이미지 출력 규약]
-기본 URL: {IMG} = https://<project-name>.pages.dev
-문법: `![]({IMG}/[ID]/[파일명].webp)`
-출력 원칙:
 1. 장소: 공간 이동 시 응답 최상단에 1회만 출력 (장소 유지 시 생략)
 2. 인물: 주요 대사/감정 변화 직전에 1회 출력 (동일 인물 연속 출력 금지)
 3. 상한: 1개 응답당 최대 2장 이내 엄수
 4. 안전: 목록에 정의된 번호만 사용, 없는 번호 날조 금지
-장소: [scene/a01:광장, scene/a02:암시장, scene/a21:폐허]
-01: [a01:기본·미소, a02:비웃음, a03:진지·살벌, a04:당황, a05:부끄러움, a06:전투]
-02: [a01:기본·단정, a02:경계, a03:통신·다급, a04:홍조, a05:화남, a06:무전]
-03: [a01:자신감, a02:도발, a03:경악, a04:부상, a05:진지]
```
